Утилита позволяет поменять коды филиала у всех подразделений организации, у которых данный код не заполнен.

Что сделать для начала: 

Предварительно, необходимо подготовить конфигурационный файл, который
находится по адресу "..\ServiceCodeChanger\Properties\launchSettings.json".
В нем указать: 
	"SBIS_URL" - ссылка на адрес сервиса Saby.
	"SBIS_LOGIN" - логин под котороым необходимо авторизоваться в системе.
	"SBIS_ORG_INN" - ИНН головной организации, коды подразделений которой нужно будет изменить.
	"SBIS_ORG_KPP" - КПП головной организации, коды подразделений которой нужно будет изменить (можно не указывать). 
	"SBIS_ONLY_WITHOUT_CODE" - флаг, где "0" - выводить все филиалы при работе программы, "1" - только филиалы без указанного кода.
	"SBIS_CODE_MASK" - маска для заполнения кодов. Например, для маски "ПОД###" два незаполненных подразделения заполнятся как "ПОД001" и "ПОД002".
	
Дальнейшие действия выполнять согласно информации в консольном выводе приложения.
