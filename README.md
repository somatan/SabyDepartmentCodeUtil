# ServiceCodeChanger

Консольная утилита для массовой смены кодов подразделений (филиалов) организации в Saby (СБИС).

Основной сценарий — заполнить коды у всех подразделений, где код пуст, по заданной маске. Также можно выбрать отдельные подразделения и задать им коды вручную.

## Настройка

Параметры задаются в файле [`ServiceCodeChanger/Properties/launchSettings.json`](ServiceCodeChanger/Properties/launchSettings.json), в разделе `environmentVariables`:

```json
{
  "profiles": {
    "ServiceCodeChanger": {
      "commandName": "Project",
      "environmentVariables": {
        "SBIS_URL": "https://online.sbis.ru",
        "SBIS_LOGIN": "ИвановИИ",
        "SBIS_ORG_INN": "1234567890",
        "SBIS_ORG_KPP": "",
        "SBIS_ONLY_WITHOUT_CODE": "1",
        "SBIS_CODE_MASK": "ПОД###"
      }
    }
  }
}
```

| Параметр | Обязательный | Описание |
|---|---|---|
| `SBIS_URL` | нет | Адрес сервиса Saby. По умолчанию `https://online.sbis.ru`. |
| `SBIS_LOGIN` | нет | Логин для входа. Если не указан — будет запрошен в консоли. |
| `SBIS_ORG_INN` | **да** | ИНН головной организации, коды подразделений которой нужно изменить. |
| `SBIS_ORG_KPP` | нет | КПП головной организации. Нужен, только если под одним ИНН несколько юрлиц. |
| `SBIS_ONLY_WITHOUT_CODE` | нет | `1` — показывать только подразделения без кода, `0` — все подразделения. |
| `SBIS_CODE_MASK` | нет | Маска для заполнения кодов. `#` — цифра порядкового номера с ведущими нулями. Например, при маске `ПОД###` два подразделения без кода получат `ПОД001` и `ПОД002`. Если не указана — будет запрошена при заполнении. |

Пароль запрашивается в консоли при запуске.

## Работа с утилитой

1. Запустите проект и введите пароль (и логин, если он не указан в настройках).
2. Утилита выведет таблицу подразделений. Подразделения без кода выделены красным.
3. Укажите, что изменить:
   - `*` — заполнить коды всех подразделений без кода по маске;
   - номера через запятую или диапазоны (`3,5,10-13`) — задать коды вручную;
   - пустая строка — выход.
4. Проверьте список изменений и подтвердите (`да` / `нет`).
5. Утилита запишет коды и покажет итог: что изменено, а что нет.

Уже занятые коды (у других подразделений и филиалов организации) повторно не назначаются.
